## Présentation du projet

**PrésenceManager** est une application mobile Android conçue pour faciliter la gestion des présences des stagiaires.

Le projet consiste à créer une interface simple, moderne et intuitive permettant d'accéder aux différentes fonctionnalités de gestion des présences.

---

## Travaux pratiques réalisés

### TP01 — Création de l'interface d'accueil

Création de la première interface de l'application avec Android Studio.

**Objectifs :**
- Création de l'interface d'accueil.
- Organisation des éléments graphiques.
- Utilisation des layouts XML.
- Personnalisation des couleurs et des textes.

### TP02 — Création du tableau de bord

Création d'une interface Dashboard permettant d'accéder aux différentes fonctionnalités de l'application.

**Fonctionnalités affichées :**
- Groupes
- Faire l'appel
- Historique
- Statistiques

**Éléments techniques utilisés :**
- ConstraintLayout
- RelativeLayout
- LinearLayout
- GridLayout
- TextView
- ImageView
- CardView
